# Task 1 – Online Reservation System (Java)

## Internship
Oasis Infobyte Internship (OIBSIP)

## Project Overview
The Online Reservation System is a simple Java console-based application that allows users to log in and perform basic railway reservation operations.

## Features
- User login authentication
- Ticket reservation
- Passenger details entry
- Train name and journey date
- Starting place and destination
- Ticket ID generation
- Ticket cancellation
- Menu-based interaction

## Technologies Used
- Java
- Scanner class
- Conditional statements
- Switch-case
- Console input/output

## How to Run
1. Open the Java source file in a Java compiler.
2. Compile and run the program.
3. Enter the demo login credentials.
4. Choose an option from the reservation menu.
